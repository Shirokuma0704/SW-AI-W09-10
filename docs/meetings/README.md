# 회의록

Project 3 기간 동안 한 회의를 여기에 모아요.

## 새 회의록 쓰는 법

1. [`_template.md`](_template.md)를 복사해서 `YYYY-MM-DD-주제.md`로 이름을 바꿔요.
   예) `2026-10-23-kickoff.md`, `2026-10-27-spt-design.md`
2. 주제는 영어 소문자와 `-`로 적어요. 이름순 정렬이 곧 시간순이 돼요.
3. `develop`으로 PR을 보내요.
